# arXiv-daily — arXiv math.AP 每日精选

每日人工筛读的 arXiv **math.AP**（偏微分方程）新到论文精选摘要，重点是流体力学方程（Euler / Navier–Stokes / MHD / Boussinesq / 原始方程等）的**稳定性、适定性、长时间行为与正则性**方向。

## 文件格式

每天一个文件，命名 `YYYY-MM-DD.md`。每篇入选论文包含：

- **作者** 与 **arXiv 链接**（abs 页）
- **一句话点评**：方法与结果定位（中文，速记性质）

文件头部带当日扫描统计（扫描总数 / new 与 cross-list 分布 / 入选数 / 边缘相关数），未入选的椭圆、抛物、几何、变分、概率及纯应用方向论文不保留。

## 收录范围

- 入围：流体方程稳定性 / 适定性 / 衰减与散射 / 正则性 / 爆破，及波动力学、量子流体等数学物理相邻方向
- 不留：与上述主线无关的方向（仅在统计中计数）

## 说明

- 点评为速记性质的个人筛读笔记，非正式综述；引用请以 arXiv 原文为准
- 更新不定期（工作日为主），每文件对应 arXiv 公告日
